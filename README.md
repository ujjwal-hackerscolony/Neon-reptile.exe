# Neon-reptile.exe
🦎 Neon-Reptile

⚡ An Interactive Neon Lizard Cursor Experience

Neon-Reptile is a creative web animation project featuring a glowing blue-green reptile-inspired cursor effect. Built to explore interactive animations, modern web design, and creative coding.

✨ Features

- 🦎 Neon reptile-inspired visual effect
- 💚 Blue-green cyberpunk aesthetic
- ⚡ Interactive cursor movement
- 🎨 Smooth animations and glowing effects
- 📱 Designed with mobile-friendly web development in mind

🛠️ Built With

- HTML5
- CSS3
- JavaScript

🚀 Getting Started

1. Clone or download this repository.
2. Open "index.html" in a web browser.
3. Move your cursor or touch the screen to explore the effect.

🎯 Project Goal

To experiment with interactive web animations and build unique visual experiences using simple web technologies.
